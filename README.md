# 💰 Expense Tracker Web App

## 📌 Overview
This is a simple and responsive web application for tracking personal expenses.  
It allows users to add, edit, and delete expenses, categorize them, and view summaries to better manage their finances.

## 🚀 Features
- Add new expenses with description, amount, and category
- Edit or delete existing expenses
- User dashboard
- View expense history in a clean UI
- Responsive design for mobile
